# 小题作答规则

## 归纳概括

**最准确的莫过于材料原词。能不变就不变，不该变的别变。**

| 内容 | 方法 |
| --- | --- |
| 审题 | 先看题干动词；“谈谈、分析”不能据此确定题型，改看作答对象是单一要素还是复合要素 |
| 原词 | 过于口语、琐碎的表达改为书面语；换不出来或换后差不多，可以保留原词 |
| 句数预判 | 字数÷25换算成行；一般按两行一句估算，对策为主时可按三至四行一句估算 |
| 句段匹配 | 段多则看无关内容与同义合并，段句相近先逐段找，段少则注意段内分层 |
| 合并 | 基于句数预判，就近同义合并；搁置争议，再看句数多少、每层多寡，决定归上或归下 |
| 前置提炼 | 在合并层次的首尾找，或在已勾画的要点中挑；优先选择首尾找到的总结词 |
| 总分关系 | 材料有总结，直接找总结句；识别首尾句总结、局部案例佐证、关键词重复，格不够时留总不留分 |
| 并列关系 | 材料没总结，连词组句；识别并列词、分号、话题转换，全留或全扔，全留可以适当缩写 |
| 阅读标志词 | 在正常阅读、理解语境的基础上，看首尾位置、最高级、递进、转折、并列、结论、引出词及特殊标点 |
| 书写空间 | 用行数÷最终句数预判每句话能否写下；换行会留下空格，结合字数压力决定 |

做法题主要写怎么干。对策后常接着效果，附带内容结合字数决定是否保留；材料把做法与效果粘连在一起时，要联系前后阅读。

### 找点遇阻

- 晦涩材料：主题词定位，圈定题干主题词，关注其所在句。
- 松散材料：高频词圈定，找出现两次或以上的有效词汇，连词组句。
- 冗长材料：大长句以逗号为单位，连接有效论述的首尾半句。

有问有答，即是答案；反复提及，即是答案；位置敏感，即是答案。

### 有问有答来检验

有疑问的要点与题干连读，检查能否回应题干问题和题干主题词。缩写是一种形式，最终目的是回应题干问题。

### 同一材料，择要点、换答法

| 问法 | 表达落点 |
| --- | --- |
| 做法 | 操作步骤，具体怎么做，可用动宾格式 |
| 经验 | 规律性策略，如“配备智能手表”提炼为“开展智能监护” |
| 启示 | 方向性认知，立足身份、突出问题及已有经验借鉴；考试中不清楚真实管理条件时，可按经验处理 |
| 影响、作用 | 突出效果，多数题目通过做法说明影响，也有纯谈影响的题目 |
| 变化 | 突出“变、更加”，如“亲属监测更便捷了” |
| 亮点 | 与众不同的做法、成效，或二者结合 |
| 原因 | 回应题干所问结果为何产生；智慧养老受欢迎一题用“得益于监测实时、操作简单”等回应 |

动宾突出行动及对象，主谓突出状态、特性或结果。并列式小标题一般前写做法，后写成效或目的；长句可抽出修饰限制成分、拆开联合成分，或通过断句使表达更短促。

## 对策建议

| 内容 | 方法 |
| --- | --- |
| 对策详细问题简 | 对策为绝对作答主体；问题尽量留概括，具体表现、原因、危害等细节留给建议。问题简写仍须全面、清楚；材料已给的对策充分时，可保留部分问题细节 |
| 是否写问题 | 两问要写问题；要求“针对性”先奔着写问题去读，若全是做法、没有问题则纯对策作答；其余纯对策作答 |
| 是否对应 | “有针对性”不是“一一对应”。要求“分别”谈问题并提“相应”建议，或明确要求“对应”“一一对应”，则每段先问题、再建议；否则集中写问题，再写建议 |
| 前置提炼 | 问题与建议分开写时，对策部分鼓励合并提炼，涵盖主要内容，各条尽量不写重；对应着写时，可以不另写对策的前置提炼 |
| 材料已给无需疑 | 材料已给对策直接照抄，价值大于自行反推；总结性的对策同样保留 |
| 围点打援 | 从问题所在自然段的例子、原因危害表现、人物说话、他地经验和情绪表达中找细节，反推具体对策 |
| 材料取舍 | 独立正例后有反例对照，先留可借鉴的细节；做法连着后文结果判断，已失效的旧做法不原样再提 |
| 建议归并 | 问题有交集，对策也会有交集，一条建议可以回应多个问题，不必强求条数相等 |

**建议问题连连看，检查遗漏项。** 检查所列问题有没有建议回应、材料送的对策有没有保留。留意材料中关于制度、机制的对策，不因表述概括而当成背景略去。

## 公文写作

| 内容 | 方法 |
| --- | --- |
| 标题 | 三类：关于＋事由＋文体；在／致＋场合或对象＋文体；宣传稿、短评等采用标题提炼型 |
| 称谓 | 根据场合、受众确定“对谁说”，重点掌握讲话稿、公开信、倡议书 |
| 导语来源 | 提炼首段＋题目要求；基本在材料首段，少数在题目问法里，极少需要全篇提炼 |
| 导语类型 | 总括型写总做法、总成效；目的型说明“让别人干”的目的；人物型交代人物、事迹、成效；定义型解释概念并回应题目 |
| 主体 | 看题目要求和材料主要内容，可能写经验做法，也可能写问题、原因、意义、建议、下一步打算 |
| 调研布局 | 成功做法材料可写工作情况、做法成效、工作启示；有问题时一般写做法成效、存在问题、对策建议；题干指定部分则按指定范围作答 |
| 新闻报道配短评 | 找准两个“锚点”，写清“通过什么，让什么更怎么样或变怎么样”；智慧养老示例由成效判断领起，再用对应做法说明 |
| 收束与落款 | “下一步”一般源于材料；通常不加落款，格式要求规范、时效性强或空间富余等情况尽量补上；明确要求格式完整的通知保留署名日期 |

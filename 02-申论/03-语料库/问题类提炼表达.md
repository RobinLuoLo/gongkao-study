# 问题类提炼表达

**问题类总结，可用“不公平”“不畅通”等词句概括。** 围绕材料中的具体对象，说明不足所在。

## 制度机制

| 问题表达 | 对应表现 |
| --- | --- |
| 体制机制不完善 | 制度安排、运行机制缺失或存在漏洞 |
| 政策标准不统一 | 不同地区、部门的政策口径、认定标准不一致 |
| 权责边界不清晰 | 职责归属不明、交叉重叠，出现推诿 |
| 协调机制不顺畅 | 跨部门沟通协作不畅，工作难以衔接 |

## 政策落实

| 问题表达 | 对应表现 |
| --- | --- |
| 政策宣传不到位 | 企业不了解已有政策，政策知晓不足 |
| 政策扶持不公平 | 政策偏重招大引强，中小微企业扶持不足 |
| 补贴发放不到位 | 符合条件、应当享受的补贴迟迟未兑现 |

## 政务服务

| 问题表达 | 对应表现 |
| --- | --- |
| 办证指导不到位 | 申办人不会操作，又找不到工作人员指导 |
| 咨询电话不畅通 | 电话改号、无人接听或长期占线 |
| 助企服务不充分 | 服务覆盖不足，企业需求未得到充分满足 |
| 服务平台不集成 | 业务涉及多个部门，缺少统一服务平台 |

## 人员与数字支撑

| 问题表达 | 对应表现 |
| --- | --- |
| 助企专员不充足 | 专员数量少，难以覆盖众多经营主体 |
| 工作业务不熟练 | 工作人员不熟悉政策业务，咨询难获明确答复 |
| 数据共享不充分 | 系统数据互通不足，部门间信息难以共享 |

## 信息公开与保护

| 问题表达 | 对应表现 |
| --- | --- |
| 信息公开不透明 | 应公开的信息不清楚，难以查询、核实 |
| 隐私保护不彻底 | 法人姓名、手机号码被公开，引发电话短信骚扰 |

## 近义辨析

- **服务不充分，业务不熟练。** 前者着眼服务供给与覆盖，后者着眼人员业务能力。“助企服务不熟练”可根据材料分别改为“助企服务不充分”或“工作业务不熟练”。
- **政策扶持不公平，助企专员不充足。** 前者着眼扶持对象与资源分配，后者着眼人员数量和服务覆盖。
- **政策补贴不充分，补贴发放不到位。** 前者着眼补贴力度不足，后者着眼已有补贴未兑现。

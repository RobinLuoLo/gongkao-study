# 浙江定位与官方出处

| 主题 | 保留的定位 | 2026年可接入的表述 |
| --- | --- | --- |
| 综合发展 | 深入践行“八八战略”；干在实处、走在前列、勇立潮头 | 经济大省勇挑大梁；奋力谱写中国式现代化浙江新篇章 |
| 共同富裕 | 高质量发展建设共同富裕示范区 | 缩小城乡、区域、收入差距；共同富裕看得见、摸得着的民生实效 |
| 科技产业 | 加快建设创新浙江 | 科技创新与产业创新深度融合；培育新质生产力 |
| 城乡民生 | 城乡融合；发展成果惠及人民 | 基本公共服务均衡可及；物质富裕、精神富有相互促进 |
| 改革示范 | 加快打造“重要窗口” | 以浙江一域之进服务全国大局；以先行探索提供实践经验 |
| 绿色发展 | 绿水青山就是金山银山 | 绿色转型与共富实践相结合；现代版“富春山居图” |

“高质量发展建设共同富裕示范区取得决定性进展，率先呈现基本实现社会主义现代化的生动图景”是“十五五”时期的目标，结尾可接“为……作出贡献”“推动……取得进展”。

## 开头省域总结

**第一步·落实态度：坚决做到“总书记有号令、党中央有部署，浙江见行动见实效”。**

**第四步·目标提升：在经济大省挑大梁中展现浙江担当，为加快建设〔创新浙江／美丽浙江〕提供坚实支撑，在高质量发展建设共同富裕示范区上谱写新篇。**

科技创新、产业升级主题可接“创新浙江”；绿色发展、人居环境主题可接“美丽浙江”。第一步选省域表达时，与通用落实态度择一接入；第二、三步仍依材料组织。

### 制造业与人居环境

因此，浙江要坚决做到“总书记有号令、党中央有部署，浙江见行动见实效”，凝心聚力、实干争先，在能源保障、绿色转型、空间优化上持续用力，推动制造业与人居环境协调发展再上新台阶，在经济大省挑大梁中展现浙江担当，为加快建设美丽浙江提供坚实支撑，在高质量发展建设共同富裕示范区上谱写新篇。

# 辩证型议论文：分段框架表达

**先点明关系，分别写清两方面如何相互作用，再转入问题与对策，结尾回扣共同目标。** 每个位置四组，段内仍调用领导讲话、经验成绩、问题导向等模型。

**A为总主题，B、C为题目的两个核心方面。** 候选保留关系和句式，具体对象与作用从材料中确定。浙江省情升华另见[[02-申论/03-语料库/分段表达/07-结尾浙江表达-省域使命与主题升华|浙江本土表达]]。

| 段落位置 | 框架任务 |
| --- | --- |
| 首段 | 点明B与C的关系，落到A |
| 第二段 | B如何带动C |
| 第三段 | C如何促进B |
| 第四段 | 两者关系中的问题或偏废危害 |
| 第五段 | 提出保障两者良性互动的对策 |
| 结尾 | 回扣B、C的关系与A的目标 |

下方以“经济高质量发展”为A、“新型消费”为B、“新质生产力”为C，代入同一参考范文检验。该范文第四段写良性循环中的痛点堵点；《简与繁》的对应位置写偏废危害。

> [!example]- 试用题目：主副标题
> 供需相促开新局  
> ——推动新型消费与新质生产力双向赋能

## 首段：点明两者关系

**01** 处理好〔B〕与〔C〕的关系，让两者各展所长、相得益彰，在统筹兼顾中推进〔A〕。

^dialectic-01-01

**02** 让〔B〕与〔C〕同向发力，在双向赋能中打开〔A〕的新空间。

^dialectic-01-02

**03** 以〔B〕牵引〔C〕，以〔C〕促进〔B〕，在相互成就中厚植〔A〕的优势。

^dialectic-01-03

**04** 统筹〔B〕与〔C〕，以相辅相成之势，开〔A〕之局。

^dialectic-01-04

## 第四段：转入关系中的问题

**01** 相互促进方能形成合力，堵点不通就难以顺畅运转。〔B〕与〔C〕的双向赋能，还须打通两者衔接中的痛点堵点。

^dialectic-04-01

**02** 两端同向，方能相互成就；衔接顺畅，才能持续发力。面对〔B〕与〔C〕互动中的现实障碍，我们仍需携手破题、协同发力。

^dialectic-04-02

**03** 良性互动不会自发形成，双向赋能也非水到渠成。〔B〕与〔C〕之间的痛点堵点仍待疏通，两者的相互促进还须合力护航。

^dialectic-04-03

**04** 让〔B〕与〔C〕彼此成就，既要看见两端的潜力，更要找准衔接的梗阻。打通堵点，才能让相互促进的优势充分释放。

^dialectic-04-04

### 偏废危害：对应讲义《简与繁》的位置

**01** 偏废任一方，都会削弱两者相互支撑的力量。唯有统筹〔B〕与〔C〕，才能让二者各展所长，共同服务〔A〕。

**02** 过犹不及，偏执则失。只顾〔B〕而忽视〔C〕，容易〔危害一〕；只顾〔C〕而忽视〔B〕，又会〔危害二〕。

**03** 一端失衡，两端受损。脱离〔C〕谈〔B〕，容易〔危害一〕；离开〔B〕谈〔C〕，又会〔危害二〕，须在统筹兼顾中把握分寸。

**04** 顾此失彼难以行稳，执一废百难以致远。把〔B〕与〔C〕割裂开来，就会削弱彼此支撑，影响〔A〕。

> [!example]- 第02组代入《简与繁》
> 过犹不及，偏执则失。只求“简”而忽视必要的“繁”，容易流于浅薄；只求“繁”而忘记应有的“简”，又会陷入冗杂。

## 第五段：协同发力，提出对策

**01** 以〔举措一〕为〔B〕培土，以〔举措二〕为〔C〕蓄能，推动两者互促共进。

^dialectic-05-01

**02** 一端以〔举措一〕清障搭桥，一端以〔举措二〕增添活力，让〔B〕与〔C〕在协同发力中形成合力。

^dialectic-05-02

**03** 把统筹兼顾的要求落到〔举措一〕与〔举措二〕上，让〔B〕与〔C〕相互支撑，共同服务〔A〕。

^dialectic-05-03

**04** 以〔举措一〕破梗阻，以〔举措二〕增活力，架起〔B〕与〔C〕协同发展的桥梁。

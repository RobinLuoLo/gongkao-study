# 小题语料库

**取材料之义，成准确之言。** 按题意选用表达，保留动作、对象与必要限定。

| 材料情节 | 表达候选 | 适用条件 |
| --- | --- | --- |
| 建“大椅子”，能躺能坐且有艺术美感 | 与村民共同动手，建设兼具艺术与实用的共享设施 | 公共共享、兼具实用与审美功能 |
| 老物件改造成家庭美术馆 | 挖掘老物件，改造文化空间 | 文化展示语境；“家庭美术馆”原词亦可保留 |
| 与村民一起动手，接近、启发村民 | 融入村民生活，开展共同实践 | 群众参与、建立联系 |
| 对乡村秩序、习俗和文脉持膜拜心态 | 尊重乡村秩序、传统习俗和文脉传承 | 态度与理念，可对应具体保护举措 |
| 古建筑面子古香古色、里子内涵丰富 | 古建筑修旧如旧，丰富文化内涵 | 兼顾建筑外观与文化内涵 |
| 乡村文明的显性与隐性价值相结合 | 兼顾乡村文明的显性与隐性价值 | 有形景观与道德、伦理、信仰等深层价值 |
| “清池范式”的具体机制 | 通过艺术介入乡建，影响村民价值判断，引导回归、共建家园 | 以尊重乡村主体和地方文化特色为前提 |
| 团队策划“烧奔塔”，重现“成人礼” | 挖掘传统习俗文化内涵，重现传统仪式 | 概括材料明确的策划与活化举措 |
| 走秀融入非遗、生产工具、旧物件 | 结合时尚风格与乡村特色，与村民共同发现美、创造美 | 文化创新、群众参与；具体载体按题意保留 |
| 艺术乡建需带来生活与审美改善 | 改善村民生活，提升审美情趣 | 直接解释运营官的目标与标准 |
| 非机动车开上人行道，行人与车辆混在一起 | 人车混行 | 概括人行道通行问题，保留材料原词 |

## 概念辨析

| 材料用语 | 核心含义 |
| --- | --- |
| 精益化管理 | 将设备、车间等硬实力与管理体系、行业质量管理等软实力结合，统筹开发、供应和产能 |
| 深度拓展 | 基于主业向高端、新能源、国际市场拓展；沿产业链上下游发展对应产业链延伸 |
| 国产化替代 | 以自主研发突破国外技术壁垒，体现研发能力及其成果 |
| 产学和就业合作 | 企业与高校协作，对接人才培养、选拔与就业；具体合作内容依据材料保留 |

# 小新第一课：讲义核对

## 题目与材料

2024年浙江省公考《申论》（B卷）第二题：根据资料7，归纳西湖区智慧养老产业的工作亮点。（20分）

要求：全面、准确，有条理；字数不超过300字。

| 材料内容 | 具体做法与效果 |
| --- | --- |
| 家属监测 | 依托“一键养老”数字应用、物联网设备，家属可实时监测老人身体健康数据等情况，实现亲情一线牵 |
| 老人使用 | 设计老人版专用界面，突出SOS与呼叫功能、放大字体；组建志愿者顾问团教老人操作，弥合数字鸿沟 |
| 日常服务 | 搭建线上15分钟生活圈，网罗周边老人所需服务商家，支持查看、预约，实现线上线下养老服务融合发展 |
| 重点群体 | 为孤寡老人等配备智能手表，提供紧急呼叫、日常健康管理，并方便与社区工作人员沟通交流 |

## 课程参考答案：亮点

有四点：一是实时监测，实现亲情一线牵。“一键养老”数字应用（以下简称“应用”），通过物联网设备，家属可实时监测老人身体健康数据等情况。

二是弥合鸿沟，实现服务一键达。设计老人版专用界面，SOS和呼叫功能在下方，字体更大，确保看清楚、精准定位；组建志愿者顾问团教老人操作，弥合数字鸿沟。

三是做优服务，实现商家一网统。搭建线上15分钟生活圈，网罗周边老人所需服务商家，形成数字版生活圈，点击应用可查看预约，实现线上线下养老服务融合发展。

四是配备手表，实现管理一手抓。为辖区孤寡老人等重点群体配备智能手表，方便老人紧急呼叫帮助，协助开展日常健康管理以及与社区人员沟通交流。

## 同一材料的问法对照

| 问法 | 课程小标题示例 |
| --- | --- |
| 做法 | 辅助实时监测；弥合数字鸿沟；网罗优质服务；配备智能设备 |
| 经验 | 搭建集成平台；弥合数字鸿沟；做优助老服务；开展智能监护 |
| 启示 | 立足拱墅区民政局工作人员身份，聚焦本区痛点，借鉴集成平台、适老改造、助老服务、智能监护等经验 |
| 积极影响 | 方便了家属监测；弥合了数字鸿沟；推动了服务融合；便利了紧急救助 |
| 变化 | 亲属监测更便捷了；数字红利更普适了；助老服务更全面了；紧急求助更高效了 |
| 亮点 | 实时监测情况明；弥合鸿沟使用顺；网罗商家服务优；配备手表求救快 |
| 受欢迎原因 | 得益于监测实时；得益于操作简单；得益于服务全面；得益于救助高效 |

亮点还可用“四个一”表达：**亲情一键牵、服务一键达、需求一键约、危险一键求**；也可突出状态：“监测方便情况明、软件适老使用顺、商家众多服务优、手表智能救助快”。

经验将具体做法提炼为策略，如“配备智能手表”转为“开展智能监护”。影响突出做法带来的结果，变化进一步突出“变、更加”。本题的原因则说明这些优势何以受到老人及家属欢迎。

# 小新第一课：归纳概括与问法转换

**申论组成要素不是孤立存在的。同一材料可以“一鱼多吃”“一鱼多做”：结合问法，精准选取材料要素，择要点、换答法。**

## 题型与作答维度

本课将题型分为归纳概括题和大作文。归纳概括包括单一概括、分析理解、公文写作；分析理解包括词语分析、语句分析、比较分析、做法评析，公文包括经验交流稿、简报、情况报告、调研报告等。大作文包括议论文（一般型、辩证型）和策论文。

| 维度 | 核心含义与常见关联 |
| --- | --- |
| 经验 | 已经做的做法并产生积极影响，基本等同于做法 |
| 问题 | 困难、挑战等，常与对策同时出现 |
| 原因 | 为什么，是什么导致、造成的 |
| 危害 | 消极作用、负面影响等，常与问题同时出现 |
| 意义 | 积极作用、效果、正面影响等，常与经验做法同时出现 |
| 启示 | 经验做法与失败教训，属于方向性认知 |
| 对策 | 打算、努力方向、解决方法等，常与问题同时出现 |

这些要素还可以衍生为分析理解、公文、大作文。

## 逐段读材料，分条写答案

1. **阅读材料：逐段分析，结合问法勾画关键词句，形成初步答案。** 以做言语理解题的思路阅读。对于课上所说的新闻稿式材料，老师强调“基本不存在相隔数段有相同点的情况”。
2. **整理答案：根据字数和点数安排分段。** 本课通常按一行25格、两行约50字安排：200字通常四点，五点及以上可不分段；250字通常五点，六点及以上可不分段；300字通常六点，也可能四点、每点约75字。200字及以上一般作分段处理，300字题基本分段。这是本课的篇幅安排，点数仍随材料确定。
3. **落笔书写：首行空两格，先说明有几点，再分条作答，标点也占格。** 通常用“一、”分点，其下可用“（一）”或“一是”。

## 做法表达：小标题与短句

做法可以用动宾格式前置提炼，如“辅助实时监测、弥合数字鸿沟、网罗优质服务、配备智能设备”。

小标题可以有不同长度：三字“助监测”，四字“辅助监测”，六字“辅助实时监测”，七字“辅助监测助安心”。并列式小标题一般是**前做法，后成效或目的**，如“提供长辈模式，弥合数字鸿沟”“配备智能设备，强化沟通交流”。

### 长句变短句

句子长短是相对的。长句改短句，主要有两种办法，另可通过断句改善阅读：

1. 抽出修饰性、限制性成分，改成分句或单独成句；剩余成分与句子主干另成一句。
2. 拆开联合成分，重复与其直接相配的成分，形成排比句式。
3. 简单断句，句型未必改变，但读起来更容易。

具体可用状语前置、断句并分解动作、更换主语、把状语变为并列分句。例如：“学生通过参与社会实践增强了社会责任感”改为“学生积极参与社会实践，增强了社会责任感”。

### 五类短语

| 类别 | 结构与示例 |
| --- | --- |
| 主谓 | 名词或代词＋动词或形容词，如“风景优美、内容丰富” |
| 动宾 | 动词＋宾语，如“发布新闻、配备智能设备” |
| 后补 | 动词或形容词＋补语，如“看清楚、去一趟、胖多了” |
| 并列 | 同类成分并列，可为名词、动词、形容词、代词、数量，如“今天明天、调查研究、雄伟壮丽、我和他、四面八方” |
| 偏正 | 修饰语＋中心语，如“我的老师、整齐地排列、长辈模式、优质商家、智能设备” |

**动宾引导读者关注行动及对象；主谓引导读者关注事物的状态、特性或结果。** 如“辅助实时监测”着眼做法，“亲属监测更便捷了”着眼变化；“实时监测情况明”则是“动宾＋主谓”的七字表达。

## 同一材料，择要点、换答法

作答不仅要求点全，也考查语言表达、语言风格，体现机关行政思维。

| 问法 | 表达落点 | 智慧养老材料中的表达 |
| --- | --- | --- |
| 做法 | 操作步骤，具体怎么做 | 辅助实时监测、配备智能设备 |
| 经验 | 从做法中提炼规律性策略 | 搭建集成平台、开展智能监护 |
| 启示 | 方向性认知，立足身份借鉴经验或教训 | 聚焦本区养老服务痛点，借鉴集成服务、适老改造等经验 |
| 影响、作用、成效 | 突出产生的效果 | 方便了家属监测、推动了服务融合 |
| 变化 | 突出“变了什么”，“变、更加”更切题 | 亲属监测更便捷了、助老服务更全面了 |
| 亮点 | 与众不同的做法、成效，或二者结合 | 实时监测，家属更放心了；软件适老使用顺 |
| 原因 | 回应所问结果为何产生 | 本题受到欢迎，得益于监测实时、操作简单、服务全面、救助高效 |

**经验与启示。** 做法是操作步骤，经验是规律性策略，启示是方向性认知。谈启示，要立足身份，聚焦本领域突出问题及已有经验：已有数字应用，就着眼适老改造等可借鉴之处。考试中不清楚真实管理者的身份条件、痛点和已有经验时，本课按经验处理启示。

**影响与作用。** 多数题目通过做法说明影响，也有纯谈影响、作用的题目。

**亮点。** “与众不同的做法＋与众不同的成效”，或其中一项，都可以构成亮点。

**本题的原因表达。** 智慧养老受到老人和家属欢迎，是因为具有“好”的价值。“缘于、得益于”即“起因于、原因是”，后接材料体现的优势及具体内容。

## 学习与复盘

**先写后听再改。** 根据讲解修订自己的答案，对照材料弄清关键词句与答案的对应关系，争取每道题能自己讲出来。

# 第二课：句段匹配、条理与阅读标志词

## 一、句段匹配

**算术只是基础，关键在于匹配。** 句数预判一般在三至八句，以三至六句居多。先看材料分段是否大致平均，再数段；有特别长的段落时，单看段数意义不大。

| 段数与预判句数 | 阅读与处理 |
| --- | --- |
| 段数大于句数 | 舍弃与题目无关的内容；几段说的是一回事，可以合并 |
| 段数约等于句数 | 先奔着“一段一句”找，不轻易废段；每段先留有效信息，最后再看 |
| 段数小于句数 | 注意段内分层，长段放缓阅读速度 |

书写前用“**行数÷句数**”预判每句话的空间，看能否写下，再决定是否换行。换行会留下行尾空格，可能挤占后面的空间。本题四句话、12行，可安排为3、3、4、2行。

换行的经验建议：300字以下不推荐换行；300字自行斟酌；300字以上建议换行，应用文注意分段与格式。

## 二、条理：合并与关键词的前置提炼

### 合并

以句数预判为基础，**就近同义合并，通常少有跳跃**。争议段落先搁置，再根据句数多少、每层多寡，决定归上或归下。

### 前置提炼

**前置提炼，就是合并的理由。** 在找点、表达相对全面准确的基础上，再做这一步加工。

1. **在每一个合并好的层次的首尾位置找。** 找概括性较强、能够包住这一层的总结词。
2. **在已勾画的要点中挑一个。** 从这一层已经选出的要点中挑合适的词。
3. 两种方法挑出的词通常可行；希望更贴近答案，优先选择第一种方法找到的词。

本题可以从材料中找到“管理、质量、创新、政府或政策”。第一课末层的“融合、提升审美、共创价值”都有道理；“共创价值”能把一起发现美、创造美等内容归在一起，概括性更强。

前置词尽量字数相等，四字与六字可以搭配，不必追求词性相对。与后文重复的是“管理、质量”等关键词，可以保留；整句重复，就不必再写一遍。

## 三、带来要点的标志词

阅读中的“小逻辑、小敏感”，用于在正常阅读的基础上增加敏感度，避免丢三落四。

| 类型 | 标志词与位置 |
| --- | --- |
| 首尾敏感位置 | 材料首尾段、段落首尾句、长句首尾半句 |
| 最高级 | 最、关键、核心、根本、本质、第一／首次 |
| 递进词 | 更、值得、进而、尤其、特别 |
| 转折词 | 不过、却、但是、然而、尽管……仍然、其实 |
| 并列词 | 还、又、另外、此外、同时、不仅……而且；序号化或顺序化表达，如一是／二是、首先／其次／再次／接下来 |
| 结论词 | 这／这些（尤其在尾句）、背后、折射、所以、因此、故此、总之 |
| 引出词 | 认为、指出、强调、表示、决定、资料显示 |
| 特殊标点 | 冒号、破折号、省略号、分号 |

词本身不是答案，要读它带出的内容。尾句中的“这、这些”常在总结前文；“资料显示”后关注数据表示的趋势，如高低、多少、强弱、增减。冒号、破折号附近注意总结；省略号后若还接着说话，注意后面的概括；分号表并列。

这些词要放在整篇材料里看，先理解语境、前言后语，读懂自然段。

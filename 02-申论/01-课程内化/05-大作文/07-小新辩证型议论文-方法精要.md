# 辩证型议论文：关系、结构与论证

**做好总括A，须处理好B与C两方面的关系。既看主题，也看材料。** A可以省略；B与C多为对立并存，具体含义及作用从题干、材料中确定。

## 识别与标题

**区分一般型与辩证型，重点看材料。** 抓住题干两个主题，判断材料内容属于一方的“子集”，还是起到两者的“搭桥作用”。

| 课堂对照 | 材料怎样展开 | 本题框架 |
| --- | --- | --- |
| 农民增收与农村消费提质 | 农村产业、农村物流、县域商业体系、政策激励起搭桥作用，促进两者良性循环 | 一般型：围绕这些具体路径组织分论点 |
| 新型消费与新质生产力 | 旅游经济、首发经济、低空经济等被归入新型消费一侧，材料展开两方面内容及其相互作用 | 辩证型：分别论证两方面及其关系 |
| 理论创新与实践创新 | “枫桥经验”来自实践，又指导实践，是两者的“辩证统一体”；材料集中写其作用途径 | 一般型：共同参与、群策群力；党组织引领、培育多元主体；立足基层、数字化赋能 |

本组三例都涉及两个主题，框架随材料的论述重点确定。“良性循环”“辩证统一”等题干字样，不能单独决定文章结构。

确定采用辩证型后，再辨明总括A是什么、B与C分别是什么。

| 课堂例题 | 总括A | 两方面B、C |
| --- | --- | --- |
| 流与留 | 人生 | 流、留 |
| 有与无 | 城市建设理念 | 有、无 |
| 手艺的创新与传承 | 手艺 | 创新、传承 |
| 新型消费与新质生产力 | 经济高质量发展 | 新型消费、新质生产力 |

标题直接写明两者关系，如“让B与C相得益彰”“奏响B与C的协奏曲”“织好B与C的双面绣”。

## 《简与繁》的六段示范

| 段落 | 主要内容 |
| --- | --- |
| 第一段：首段概述 | 点明两者同时存在、同等重要；解释B、C的含义，说明处理好两者对A的意义；因此，做好A，需要平衡B与C的关系。缺少定义时，可用意义、背景、问题、政策或讲话引出观点。 |
| 第二段：B的价值 | 讲B的意义好处及其与C的联系。讲义示范为“B是A的基础，对于C具有前提作用”。 |
| 第三段：C的价值 | 讲C的意义好处及其与B的联系。讲义示范为“C是A的保障，对于B具有重要价值”。 |
| 第四段：偏废的危害 | 只重视B、忽视C会怎样；只重视C、忽视B又会怎样。两方面可合写，也可拆成两段。 |
| 第五段：两方面对策 | 因此，做好A，一方面做好B并提出对策，另一方面做好C并提出对策。 |
| 第六段：结尾 | 回扣B、C的关系与A的目标，沿用一般型议论文的结尾方式。 |

第二、三段与一般型议论文的论证逻辑相同，将B、C分别作为分论点，可调用成功经验型等论证方式。基础、保障等关系用语依材料中的具体作用组织。

## “新型消费与新质生产力”：良性循环

**本题重在“良性循环”。** 总目标是经济高质量发展，两方面是拓展新型消费、发展新质生产力。论证要写出两者如何相互作用、共同发力。

精简讲义的两种开头，分别以“意义价值＋定义含义＋意义价值”和“经验成绩＋意义价值＋形势背景”引出同一主张：将壮大新型消费与培育发展新质生产力有机结合，推动形成供需更高水平的动态平衡和国民经济的良性循环。

本地真题参考范文《新型消费与新质生产力的双向赋能》按以下顺序展开：

| 段落 | 论证任务 |
| --- | --- |
| 首段 | 交代背景、说明两者特征，提出相互融合、相互赋能的关系 |
| 主体一 | 论述拓展新型消费，结合技术创新、消费形态变化，写其对新质生产力的带动作用 |
| 主体二 | 论述发展新质生产力，通过优化生产方式、提升供给质量，释放新型消费潜力 |
| 过渡 | 由良性循环的意义转入生产、消费及循环中的痛点堵点 |
| 主体三 | 政府政策扶持与企业协同发力，共同保障双向赋能 |
| 结尾 | 回扣两者关系，落到经济高质量发展 |

《简与繁》以“两方面价值—偏废危害—两方面对策”展开；本篇以“两方面相互促进—循环中的堵点—协同保障”展开。段内仍可调用讲话、经验、问题等模型，段落之间要共同说明题目要求的关系。

## 《简与繁》的落笔要点

1. **首段解释含义。** “简”是说清楚、化繁为简；“繁”是恼人却必需的繁复。定义讲清即可，意义的展开留给第二、三段。
2. **分别论证，并写出联系。** 手机点单、叫车、缴费等体现“简”的便利；读懂一首短诗需要了解作者、背景、典故，说明经历“繁”能够帮助理解“简”。
3. **用材料反说偏废的危害。** 微小说的简短来自千思万绪、良苦用心；反过来说，缺少这些投入，作品可能不受欢迎。只求繁复，则可能被琐事牵住、耗费精力。保留例文中的“可能”。
4. **两方面分别提出做法。** “简”落到去芜存菁、轻装上阵；“繁”落到沉心了解、详尽思考、弄懂学透。
5. **结尾照应关系。** 用材料、母体范文或核心金句收束，回到简繁平衡与生活目标。

# 大作文论证段：配色示例

<span style="color:var(--color-blue)">蓝色：材料内容及材料原有金句。</span> <span style="color:var(--color-purple)">紫色：可积累的衔接、分析和组织表达，包括总结的组织。</span> 分论点保留正文色。

## 成功经验型：农业科技

以农业科技为抓手，推动生产经营提质增效，为科技服务社会、造福人民提供支撑。

<span style="color:var(--color-blue)">“人民的需要和呼唤，是科技进步和创新的时代声音。”盐碱地因开发难、农业产量低、养殖利润率低，大量未得到高值化利用。某科研团队紧盯群众需求、发展需要开展科技攻关，逐步攻克青蟹在盐碱地养殖、出效益、标准化生产等难题，又成功试养十余种海鲜，将盐碱瘠土变成良田，为农业生产经营提质增效、精准帮扶提供科技方案。</span><span style="color:var(--color-purple)">当然，农业科技的创新突破绝不是轻轻松松、敲锣打鼓就能做到的。</span><span style="color:var(--color-purple)">因此，要继续把群众需求作为科研方向，敢于突进深水区、啃硬骨头、涉险滩，把论文写在乡间田野，切实解决群众的急难愁盼，用科技惠及人民、造福人民。</span>

| 段落位置 | 内容作用 |
| --- | --- |
| 领起 | 提出农业科技这一分论点，并回应全文主题 |
| 材料 | 原有金句、存在问题、科研做法及其成效 |
| 转合 | 从成功实践转向继续攻坚的必要性 |
| 总结 | 回扣需求导向，把继续推进落到科研行动 |

## 问题导向型：区域协调发展

聚焦改革重点、解决实际问题，就要促进区域协调发展。

<span style="color:var(--color-blue)">浙江山区县发展有所提速，但受基数差异影响，区域间绝对差距仍在拉大，城乡协调发展也面临瓶颈。</span><span style="color:var(--color-purple)">行进至今，协调发展“低垂的果子”都摘掉了，剩下的都是难啃的“硬骨头”。困难，就是压力“测试器”。志不求易者成，事不避难者进。</span><span style="color:var(--color-purple)">因此，要聚焦区域协调中的卡点堵点，引导壮大主导产业、培育新兴产业，创新体制机制、推进农村改革，以务实行动打开协调发展新局面。</span>

这一组依次完成：难度升级—认识困难—迎难而进—提出行动。“因此”承接的是前面的分析，具体措施仍从题目材料中组织。

## 生活科技范文中的持续推进

<span style="color:var(--color-blue)">智能小家电在“沉浸式”回家视频中纷纷出场，展示轻松、有品质的居家生活，体现科技推动生活品质改善。</span><span style="color:var(--color-purple)">生活科技的创新突破只有进行时，没有完成时。</span><span style="color:var(--color-purple)">因此，要持续回应生活需要、拓展应用场景，让科技创新成果更好服务日常生活。</span>

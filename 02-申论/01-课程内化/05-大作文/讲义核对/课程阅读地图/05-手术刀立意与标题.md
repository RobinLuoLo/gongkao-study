## 主副标题：先找准材料中的“伟大事业”

第12—13页从题干的“梦想、创新、实干”，回到材料一科学家的科学追求，明确“伟大事业”指向建设社会主义现代化国家，最终题目为：

> **以梦想、创新、实干助力伟大事业**  
> ——把科学追求融入建设社会主义现代化国家中去

这是明确写有“最终的题目为”的正面原例，与八大模型完整版第110页一致。主标题保留题干三个关键词并表达观点，副标题把材料所指的具体事业说清楚。后续采用主副标题时，可让主标题更凝练、有文学色彩，副标题仍须完整落到材料立意；这是依据范例形成的使用方式，不冒充老师逐字讲过的通则。

第15—16页反例说明，不能随意更换“乡村振兴”“解决实际问题”“无名英烈”等主题词。第15页批评“科技点亮美好生活/未来”，针对2024年A卷材料中现代化事业的立意；不能据此否定另一题本就以民生为总主题的标题。

第18页彩色新型消费文章是完整五段课堂展示稿，主标题为“奏响拓展新型消费和发展新质生产力交响曲”，副标题为“为高质量建设共同富裕示范区提供坚实力量”。它处于“盲目引用时政”及“论证内容和论点关系”的讲解之后，图本身未单独标明推荐或逐项批改，故不作已明确推荐的范文。与精简版第38—39页同题开头示范并非同一长度、同一措辞版本，不能拼接成一个原文。当前主副标题的直接正例以第13页为准。

## 总分论点与模型的先后关系

第2—9页以同一“制造之变”样本说明：材料五讲话引出总论点；材料四、六提供专注、创新、技改等分论点及经验论据；材料七国际国内和浙江背景可用于过渡、结尾。首段、分论点和结尾因此能分别调用讲话、经验、背景，而不是先备一套金句再硬填材料。

第6页列出的“准确把握国际国内环境变化”等宏观说法，在本题中难以靠具体材料展开，属于不适合本题分论点的反例。这里不等于所有议论文都不许使用宏观概括。

第10—14、19页的路径为：**大作文题干 → 所引语句、段落 → 小题未用材料 → 全篇材料**。按线索层层递进，不把“优先未用材料”改成“一律不读小题材料”。第62页找乡村人才时，就回到小题已经使用的职业经理人材料。

第11页画圈图需连同图中文字读，原关键词为“子集”“搭桥作用”“辩证统一体”。农民增收与农村消费提质一题，农村产业、农村物流、县域商业体系、政策激励在两者之间搭桥，判一般型；新型消费与新质生产力一题，旅游经济、首发经济、低空经济被放入新型消费一侧，提示从材料归属及相互作用判辩证型；理论创新与实践创新一题，“枫桥经验”位于交集、是辩证统一体，材料讲其具体作用途径，仍判一般型。图解用于观察本题材料怎样组织，不作为严格集合公式，也不把某个产业永久归入一侧。三个题目都涉及两主题，须分别核材料，标题的两者型及“协奏曲”等比喻不代替这一步判断。浓缩对照见[[07-小新辩证型议论文-方法精要#识别与标题]]。

## 六把刀：提炼时具体看什么

| 原方法 | 必须保留的辨认动作 | 原例锚点 |
|---|---|---|
| 领导讲话 | 从讲话弄清主体、背景、问题、对象、要求与意义；分论点再在材料里找依据 | 24—25页科学追求与三个分论点；26—27页工程科技；33—35页枫桥经验 |
| 标点符号 | 关注引号突出、反复被解释的实质词，而非把引号内任何词都升为论点 | 38页专注、创新；39—40页技改；40—43页科技金融、快递进厂；44—45页以旧换新 |
| 重复 | 反复出现的词可能是材料中心，须与题干主题合读 | 46—48页创新中心、“客货邮”；49—52页青年就业三方向 |
| 题目主题 | 抓住材料表达如何作用于题目目标，尤其辨明作用方向 | 53页县域商业；54—57页生产力推动消费、消费反向牵引生产力；58—62页人才队伍 |
| 总结性词句 | 从材料自身的总结句提炼分论点，再用事例支撑 | 63—67页枫桥经验的三方面 |
| 并列关系 | 判断并列的是做法、意义还是其他要素，保持层级相近 | 68—71页经济、政治、文化、情感互联互通 |

第33页关于“宏观背景”和“Z省H市”材料线索是经验性提示，老师同时举枫桥经验也有代号的例子；不能改成机械识别规则。

第48页认为“客货邮融合发展”比“农村物流服务”更精准，也可写成“融合发展客货邮，优化农村物流服务”，同时保留具体抓手与概括。第51页回乡与基层存在交叉，不以助手自设的互斥分类替换老师论点。

第54—57页对辩证题特别有用：旅游中AI、智能服务体现生产力促进新消费；首发经济、交叉融合及消费升级牵引产业链，体现消费促进生产力。换文学框架时仍应保留这两个作用方向。

第63—67页“理论与实践”题，老师基于枫桥经验的实际做法选择一般型。这是本题讲解，不推成“凡理论与实践都写一般型”的定律。

## 明确强调与范例性质

| 锚点 | 原义 | 后续如何使用 |
|---|---|---|
| 13 | 最终主副标题 | 副标题补明“伟大事业”的材料所指；主标题也有观点和关键词 |
| 15—16 | 丢落、删减、变换主题有偏题风险 | 先保留题干关键关系，再优化语句 |
| 16—17 | 把工程科技局部成绩当科技全部成绩，属总分层次错位 | 首段概括工程、农业、生活的共同成绩；局部事例放对应分论点 |
| 17 | “中国现代化伟大事业”等表述不精准 | 使用规范、完整的政治表达，具体出处另查 |
| 17—18 | 盲引时政，论证后不回扣论点 | 先建立引用内容与本段论点的关系 |
| 18下方 | 核心立意未在首段表明 | 老师强调用“因此”明示总论点；这是课程操作建议 |
| 19、72 | 具体务实、精炼易懂、简单好写 | 文学化不消解具体对象与动作；不是追求空泛高度 |
| 71 | 经济政治文化情感四类价值 | 可以用意义型分论点，不强制全部改成对策 |
| 79—81 | 学生科技作文反例 | “增强国家实力、实现产业兴旺、便利生活”与本题具体领域抓手不匹配；不能抄走其金句当成老师范文 |
| 85 | 黄色“以下错误案例” | “工程/农业/生活”删除“科技”后与框架搭配失当；标黄可能是在标错例 |

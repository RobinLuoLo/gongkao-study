# 金句金段：五定写作与模型调用

**金句承担串联、加工材料的作用。一段可组合多个模型，同一模型也可用于不同段落。** 学习重点是从材料中来、到材料中去，识别要素、组织论证，再选择贴切的表达。

## 五定写作法

| 顺序 | 要确定的内容 |
| --- | --- |
| 定材料 | 找到总、分论点的材料来源。 |
| 定论点 | 确定全文主张及本段要论证什么。 |
| 定模型 | 判断材料中的要素属于讲话、经验成绩、问题、背景、政策、意义、定义或人物，可组合使用。 |
| 定结构 | 确定模型组合方式及先后顺序，如经验成绩用总分、分总、时间结构。 |
| 定金句 | 根据前后的论证需要，补上评价、归结、转合或呼吁。 |

## 八大模型

按课程重要性顺序列示：

| 模型 | 材料要素与成文着力点 |
| --- | --- |
| 领导讲话 | 承接讲话、指示、回信等，说明其指明的方向、提出的要求、寄予的期望，再引出本题主张。评价贴合讲话的具体内容。 |
| 经验成绩 | 组织问题、做法、成效，归结实践说明的道理；可用问题、形势或意义转合，再回扣论点。 |
| 问题导向 | 点明本题困难，说明如何认识这些问题，再引出针对性的行动。放在首段时，须同全文论证基调相合。 |
| 形势背景 | 交代发展方位、机遇与挑战，说明其对本题工作提出的要求，再引出主张。地域、主体与任务依题意衔接。 |
| 政策落实 | 承接政策或会议部署，说明落实任务及推进路径，再结合问题、成效转入具体行动。 |
| 意义价值 | 用“实践充分证明”等归结材料，讲清做好某事对主题目标的作用；也可整体论证某项工作的必要性。 |
| 定义含义 | 解释概念或引句的关键含义，联系题目说明启示；可与讲话、经验成绩、问题或背景组合。 |
| 人物学习 | 从事迹提炼品质、精神，联系写作身份、现实背景、需要解决的问题与意义，转向当下践行。 |

## 领导讲话：理解、关联与下落一层

原课主干：**阐明重视（金句引领）＋列举讲话＋讲话本身理解＋起到作用＋下落一层＋因此总结。** 讲话本身理解、作用评价须贴合具体内容；“下落一层”依据讲话与题目主题的内在关系决定。

- **讲话与主题有距离：**补出二者的联系，以“工作关键”“发力重点”“有效抓手”“重要一环”“主攻方向”“着力点”“突破口”“牛鼻子”“切入点”“支撑点”“先手棋”“牵引器”等将讲话要求落到本题。例如，讲话谈发展新质生产力，题目谈生产性服务业，可承接为“做强生产性服务业是重要一环”。
- **讲话与主题直接对应：**理解其指引与要求后，直接引出本题主张。例如，讲话要求科技服务经济社会、造福人民，与“科技要服务社会、造福人民”的主题直接对应。

讲话中的殷切希望、具体要求、理论关系等，分别贴合其内容评价。用于结尾时，转为“让我们”“只要……就……”等号召呼吁、坚定信心的文风。

## 经验成绩：材料结构与起承转合

原课论证结构：**金句引领＋成功经验（问题＋做法＋成效）＋起承转合（问题或形势背景或意义）＋因此总结。** 成绩表达兼顾做法与成效，总经验成绩与分经验成绩可颠倒顺序。

| 原课展示结构 | 组织方式 |
| --- | --- |
| 总结构 | 概括总体成绩，再转合、引出主张。 |
| 分（事例并列）结构 | 并列多个做法与成效，归结共同意义，再引出主张。 |
| 总分（分总）结构 | 总体成绩与具体领域、具体案例相结合，先总后分或先分后总。 |
| 时间结构 | 过去谈问题，当下谈成功经验，未来谈下步打算、回扣分论点。 |

讲义另以王欢团队盐碱地养殖海鲜，展示单事例成文及其时间结构改写。同一材料可按论点与段落任务调整组织方式。

起承转合为总分论点的引出作铺垫。本节常见转合表达“取得成绩不应骄傲”；存在问题、形势背景、意义等也可承担转合作用。理解结构后结合材料取舍。

## 同一模型，依段落任务换结句

| 使用位置 | 组织任务 | 科技母题中的落点 |
| --- | --- | --- |
| 首段 | 经评价、解释或转合引出总论点 | 因此，以科技服务社会、造福人民。 |
| 问题成绩段 | 承接材料的成绩、问题或背景，引出下文分论点 | “关键要从以下三方面做起”。 |
| 分论点段 | 用材料支持本段主张，转合后总结本段行动 | 农业科技案例之后，回到需求导向、科研攻关与生产经营提质增效。 |
| 结尾 | 用讲话、问题或背景引出呼吁号召，回扣总、分论点 | 以“让我们”“只要”等收束工程、农业、生活科技的行动与共同目标。 |

经验成绩、问题与背景可相互组合，模型随段落任务取舍。精简版的长“母题段”用于展示各模型如何拼接；实际成文按本段需要删减，保留与题意相接的内容。

## 连接句怎样服务论点

材料给出“做了什么、产生什么变化”，接下来说明“这些事实对本题意味着什么”，再以“因此”提出本段主张或行动。归结的主语、对象、结果与总分论点保持衔接。

农业科技案例中，盐碱地开发难、产量与效益低，是现实需求；王欢团队科研攻关、成功养殖，是做法与成效；由此可以论证农业科技回应群众需求、推动生产经营提质增效。之后再承接持续攻关的要求，回到科技服务社会、造福人民。

三色标记用于辨认文字来源与功能：黑色是个人表达，蓝色是材料内容，紫色是可迁移的核心连接、分析与组织表达。材料原有引语仍随材料标蓝。

## “因此”后的总论点怎样组织

讲义用四组AI指令拆分可调用表达：第一组写贯彻落实的态度与决心；第二组选四字短语；第三组用“啃硬骨头”“牵牛鼻子”等形象化抓手；第四组整理发展定位，用于提升落点。

实战按“**因此＋贯彻落实的态度＋行动短语或形象抓手＋本题总分论点＋发展目标**”组织。第二、三组共同服务于行动表述；总分论点根据题干和材料确定。发展目标依主题、地域和身份衔接。

**总结四步：落实态度 → 行动状态或方法 → 本题主张与举措 → 目标提升。** 其中行动表述可调用四字短语或形象化抓手，实际主张来自题目与材料。

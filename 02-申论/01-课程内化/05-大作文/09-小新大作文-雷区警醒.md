# 大作文：雷区警醒

**紧扣主题，先确定论证所需的材料，再确定金句，最后组织成段。** 八大模型服务于本题的写作思路。

## 成文的七项检查

| 部位 | 检查重点 |
| --- | --- |
| 题目 | 紧扣主题，检查关键词有无丢落、删减、变换 |
| 首段 | 紧扣主题，以宏观视角引出总论点 |
| 总论点 | 扣住主题、体现高度，与题目和分论点一致 |
| 分论点 | 为总论点服务，具体务实、精炼易懂、好写速成 |
| 结尾 | 回扣主题，再次提升文章高度，收束完整 |
| 论证 | 紧扣总、分论点，始终把握写作总遵循 |
| 结构 | 段落长短协调；本课范例以每段200—250字检查篇幅失衡 |

## 段落始终落在本题

- **总分论点对应。** 分论点从总论点下落到具体的小主题，段内材料、分析和总结都为这一小主题服务。写“工程科技”，论证就要落到工程科技的突破及其作用。
- **金句接住论证。** 意象、讲话、嘱托须有具体所指；写“贯彻要求”，前文须说明是什么要求、材料如何体现。连接表达随本题内容组织。
- **升华照应主题。** 题目、总论点和结尾的落点一致；浙江表述结合文章主题使用。固定政治表述保持完整，如“以中国式现代化全面推进强国建设、民族复兴伟业”。

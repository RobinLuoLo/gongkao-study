# 第五课例题与参考答案

## 题目

> 请根据“给定资料4”，梳理S市公共文化空间建设和运营中存在的问题，并提出解决建议。（20分）
>
> 要求：（1）问题梳理全面、准确；（2）所提建议具体明确、有针对性、切实可行；（3）不超过450字。

## 审题与组织

“有针对性”未要求一一对应。问题可按建设、运营两方面集中表述，再分条写建议。450字约18行，按“问题一大句＋约五条建议”预估；材料共九个自然段，可作少量合并。

## 课程参考答案

> 问题：建设方面，一是缺少统筹规划，效仿跟风；二是文化遗存利用不力，成熟载体规模小且分散，新建载体远离市区，内容泛化陈旧。运营方面，一是民营创始人经营管理能力欠缺；二是服务人群局限，使用率低；三是风格、设施与服务同质化严重，易审美疲劳；四是空间场景被当作网红打卡点，空间文化内涵、价值观念、特色功能被忽视。

> 1. 做好统筹规划。由市级部门根据各区特点因地制宜规划项目，做到主题多元、优势互补。

> 2. 加强设计创新。考虑辐射范围、交通等因素做好选址与体量设计，依托文化遗存打造现象级文化，鼓励主题型和创新创意类建设，做好线上宣传。

> 3. 重视能力培养。开展经营管理能力交流培训，鼓励有人文情怀和企业家精神的文化名家参与运营。

> 4. 丰富经营形式。开展各类文化活动，吸引各年龄段群众，在服务上体现个性特点和差异化。

> 5. 输出文化价值。举办非遗表演，针对不同需求定制活动和课程，实现教育功能。

## 材料取舍

| 材料内容 | 课堂处理 |
| --- | --- |
| 畅雅艺术空间独立成段，后接冷清的反例 | 先留便利、辐射、活动等小词；最后已有充分对策时，不必全部带进答案 |
| 各区缺啥建啥，其他地区效仿，生存堪忧 | 结合整段结果看不足，反推由市级部门统筹规划 |
| 社区书院以儿童使用为主、场所冷清，工作人员建议多搞活动 | 问题写清服务人群局限与使用率低，保留活动建议 |
| 书店装修后曾改善，后来设计风格、设施尤其服务仍同质化 | 不把旧装修做法直接作为新建议；抓住差异化服务改进 |
| 美术馆被当成打卡点，文化内涵、价值观念、特色功能被忽视 | 保留具体问题，借末段文化价值输出与教育功能回应 |
| 黄馆长介绍外地经验，再谈本市规模、布局、创意等不足 | 已给做法与问题合着看，保留选址、体量、文化遗存、主题创意等内容 |
| 博物馆非遗表演、定制活动课程与文化价值输出 | 材料直接给出对策，保留“定制”及教育功能 |

## 建议回应检查

| 建议 | 主要回应 |
| --- | --- |
| 统筹规划 | 各区主导、效仿跟风带来的布局问题 |
| 设计创新 | 文化遗存利用不足，载体小且分散或偏远，主题与创意不足 |
| 能力培养 | 创始人经营管理能力欠缺 |
| 丰富经营形式 | 服务人群局限，以及同质化、审美疲劳 |
| 输出文化价值 | 只拍照打卡，文化内涵、价值观念和特色功能被忽视 |

本题六项问题、五条建议可以相互回应，检查覆盖情况即可，不要求数目相等。

# 公文写作：方法精要

申论以事务性公文为学习重点，常见的有讲话类、宣传类、信息类、调研报告类。写作重点是**标题、称谓、导语（首段）、主体、结尾和落款**；具体内容看题目要求和材料主要内容。

## 标题：掌握三类写法

| 类型 | 写法与适用文体 |
| --- | --- |
| 事由＋文体 | 关于＋事由＋文体，适用于计划、规划、方案、总结、调查报告、建议等；“关于”是否保留，看是否通顺 |
| 场合或对象＋文体 | 介词“在／致”＋场合或对象＋文体，如《在全市经济工作会议上的讲话》《致社区居民朋友的一封信》 |
| 标题提炼型 | 常见于宣传稿、短评、简报、短文，如《文化之光照亮乡村共富路》 |

## 称谓：确定“对谁说”

根据场合、受众选择，重点掌握讲话稿、公开信和倡议书。

| 文体 | 称谓落点 |
| --- | --- |
| 讲话稿、发言稿 | 场合与听众，如“各位领导、同志们” |
| 公开信 | 面向的公众，如“广大市民朋友们” |
| 倡议书 | 倡议对象，如“全体党员同志”“社会各界人士” |
| 建议信、意见信 | 收件单位或个人 |
| 邀请函、请柬 | 受邀对象 |
| 欢迎词、欢送词 | 活动性质与来宾 |

## 导语：提炼首段＋题目要求

导语是对材料的高度概括。**基本从材料首段找，少数在题目问法里，极少数需要从整篇材料提炼。**

| 类型 | 写什么 |
| --- | --- |
| 总括型 | 最常见。找到或概括总做法、总成效，讲清“干了什么、干得怎么样” |
| 目的型 | 建议书、倡议书、通知等，目的是“让别人干”，说明为什么开展这项工作 |
| 人物型 | 本质也是总括型。集中交代“他是谁、做了什么、取得什么成效”，再回应题目要求 |
| 定义型 | 解释题目中的概念，再结合材料回应题目；较少见 |

总括型中，宣传稿首段一般可用**案例列举＋总做法＋总成效**；情况报告、经验介绍一般用**总做法＋总成效**。

目的型分三种：**巩固成效**，在已有工作基础上扩大队伍、做优服务；**落实决策**，承接上级部署，提出本单位参与或落实的安排；**问题导向**，从现实困难、工作不足引出开展行动的目的。

## 主体：看题目要求和材料主要内容

一般写经验做法，也可能写问题、原因、意义、建议或下一步打算。要求介绍“特点和运行情况”，就围绕特点及其具体运行展开；要求“问题与建议”两部分，就按这两部分组织。

调研报告的布局随材料变化：材料全为成功做法，可写**工作情况—做法成效—工作启示**；材料有问题，一般写**做法成效—存在问题—对策建议**。题干限定作答部分时，以限定内容为准。

## 短评：找准两个“锚点”，突出影响成效

宣传稿着重介绍亮点、引导行动；短评重在评论分析，要求观点明确，可以从问题、原因、影响、对策等角度评价。宣传稿的特点是简洁明了、强调亮点、引导行动、传播广泛；短评的特点是简短精炼、具有评论性质、可以多角度评价。

本课重点讲新闻报道配短评：从报道中提炼内容，强化宣传，突出成效，绝大部分讲带来的影响。

**从题目找准两个“锚点”，写清“通过什么，让什么更怎么样，或者变怎么样”。**

| 题目 | 要讲清的关系 |
| --- | --- |
| 文化之光照亮乡村共富路 | 文化让乡村发生了什么变化 |
| 行政执法护航新型消费 | 行政执法让新型消费发生了什么变化 |
| 当数字技术遇上传统农业 | 数字技术让传统农业发生了什么变化 |

这类短评标题常呈双主题形式。内容要围绕两者的关系写成效。智慧养老示例中，首段由总做法引出“智慧养老是照亮老年人幸福晚年的新路径”这一总判断；主体各段由成效领起，再写对应做法：

> 智慧养老，让亲属监测更便捷了。设计“一键养老”数字应用，嵌入物联网设备，帮助家属实时监测老人情况、掌握身体健康数据，推动实现亲情一线牵。

同一组材料，经验交流写“做实智慧支撑，辅助家属监测”，短评则写“智慧养老，让亲属监测更便捷了”，后面的具体做法用来说明这一成效。

## 结尾与落款：结合文体、材料和格式要求

经验交流中的“下一步”一般源于材料；情况介绍可用“以上就是我的讲解，谢谢大家”收束。宣传稿、短评示例则在主体内容写完后结束。

本课在字数限制下通常不加落款；遇到格子富余、格式要求规范、题目时效性强等情况，尽量补上。明确要求“格式正确、要素完整”的通知，要写清称谓、目的、会议时间、地点、与会对象、议程，以及署名、日期；题干另要求详列座谈提纲的，还须落实这一任务。

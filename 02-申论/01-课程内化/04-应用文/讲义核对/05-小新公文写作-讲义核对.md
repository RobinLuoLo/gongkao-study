# 公文写作：讲义核对

## 智慧养老：同一材料，一鱼多做

| 材料内容 | 经验交流的表达 | 短评的成效判断 |
| --- | --- | --- |
| 数字应用嵌入物联网设备，家属实时监测老人健康数据 | 做实智慧支撑，辅助家属监测 | 智慧养老，让亲属监测更便捷了 |
| 老人版专用界面，突出求助功能；志愿者教操作 | 提供长辈模式，弥合数字鸿沟 | 智慧养老，让数字红利更适老了 |
| 线上15分钟生活圈汇集周边商家，支持查看预约 | 网罗优质服务，实现融合发展 | 智慧养老，让助老服务更全面了 |
| 为孤寡老人等配智能手表，支持求助、健康管理与沟通 | 关注重点群体，配备智能设备 | 智慧养老，让紧急求助更高效了 |

| 作答任务 | 标题与首段 | 主体及收束 |
| --- | --- | --- |
| 工作经验交流 | 《在养老服务产业发展经验交流会上的发言》；首段总括总做法、总成效 | 四项经验；“下一步”一般源于材料 |
| 宣传介绍 | 《西湖区向“新”而行 布局智慧养老产业》；首段总括做法成效 | 展开四项做法与成效，写完即结束 |
| 到西湖区调研值得肯定的做法 | 《关于西湖区智慧养老产业的调研报告》；交代调研任务 | 工作情况、主要做法及成效、工作启示 |
| 接待考察，介绍特点和运行情况 | 《关于“智慧养老”的情况介绍提纲》；总括后引出“特点和运行情况” | 监测方便情况明、软件适老使用顺、商家众多服务优、重点突出救助快；以讲解谢语收束 |
| 新闻短评 | 《智慧养老照亮幸福晚年》；由总做法引出“智慧养老是照亮老年人幸福晚年的新路径” | 四项成效判断领起，各用对应做法说明 |

### 总括型首段

> 近年来，西湖区以打造“一键养老”数字应用为牵引，向“新”而行，积极布局智慧养老产业，“老有所安”在西湖区得到了生动体现，最美“夕阳红”成为西湖区一张“金名片”。

核心是总做法、总成效。配套答案的注释还逐项点出上级部署、聚焦群体、聚焦目标、总做法、回扣题目、落脚成效；有具体成效时，可用材料已有的数据、评价体现。总做法既可概括为“一键养老”数字应用，也可统摄为“辅监测、弥鸿沟、优服务、配手表”。

### 调研报告的材料条件

智慧养老材料全为成功做法，因此示例布局为“工作情况—做法成效—工作启示”，启示为坚持科技赋能、考虑老人实际、保障服务质量、突出重点人群。材料有问题时，一般采用“做法成效—存在问题—对策建议”。

山岔村题同样要求调研“值得肯定的做法”，答案在概括村庄变化后，按争取资金、流转土地、因地制宜发展旅游、软硬并举提升精神风貌展开。

## 格式与任务核对

### 会议通知

题干明确要求“格式正确、要素完整”，并须详列座谈提纲。

1. 标题：《关于召开座谈会的通知》。
2. 称谓：各相关企业。
3. 首段：召开会议的目的、决定召开座谈会，引出“有关事项通知如下”。
4. 主体：会议时间、地点、与会企业名单、会议议程；座谈内容按题干要求详列。
5. 落款：S街道、日期。

### 只写报告的指定部分

快递配送从业青年调研题要求撰写报告中“问题”与“建议”两部分的提纲。讲义同时展示了标题、导语、基本情况、存在问题、工作建议的整篇报告框架；本题实际作答范围为题干限定的两部分。

## 公文分类

法定公文15种：决议、决定、命令（令）、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。

事务性公文是本课重点，按课程分类如下：

| 类别 | 用途与常见文体 |
| --- | --- |
| 计划类 | 预安排工作，如计划、规划、方案 |
| 总结类 | 回顾评价工作，如总结、述职报告 |
| 调查报告类 | 问题现状与对策，或经验与启示、工作建议 |
| 讲话类 | 会议、公开场合发言，如讲话稿、演讲词 |
| 建议类 | 提出问题解决方案，如建议信、提案 |
| 宣传类 | 政策宣传、倡议，如公开信、宣传手册；短评提炼强化新闻宣传 |
| 信息类 | 内部传递信息，如简报、情况反映 |
| 方案类 | 明确具体实施步骤，如整改方案、工作方案 |

本课按重要性排列：讲话类、宣传类、信息类、调研报告类。

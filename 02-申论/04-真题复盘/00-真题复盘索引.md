# 真题复盘

**由原答定位问题，由修改提炼方法，由再用检验认识。**

## 浙江选调实写

**选调真题写一遍，在复盘中筛定考前表达。** 公文与大作文都依题作答；大作文先检查扣题、总分论点与材料论证，再检查金句衔接、总结和收束。

| 重点 | 本轮任务 |
| --- | --- |
| 领导讲话、经验成绩 | 重点掌握，结合真实作答选定顺手的衔接表达 |
| 问题导向、意义价值、政策落实 | 各选一个表达，连同前后承接关系一起掌握 |
| 分论点框架 | 从已有成组小标题中选择能准确容纳本题论点的写法 |
| 结尾升华 | 回扣主题后选择相合的发展目标；浙江表述服从题目范围 |
| 辩证型议论文 | 以“新型消费与新质生产力”范文对照两者关系与段落安排 |
| 策论文 | 结合后续提供的范文，学习以对策统领分论点、展开具体措施 |

每篇保留原答和必要的修改对照，集中解决最影响成文的1—2处问题。表达从既有语料中试用、比较，再由本人确定背诵选择。

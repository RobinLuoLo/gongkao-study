# 资料分析02｜基期与增长量速算

## 一、A、B、r、x 的关系

基期 $A$ 是用来比较的上一期量，现期 $B$ 是本期量，$x$ 是增长量，$r$ 是增长率。增长率以**基期**为分母；下降时 $r$ 和 $x$ 为负。四量的基本关系为：

$$
B=A+x=A(1+r),\qquad x=B-A=Ar,\qquad r=\frac{x}{A}=\frac{B}{A}-1.
$$

| 已知 | 可直接求得 |
| --- | --- |
| $A,B$ | $x=B-A$；$r=x/A$。 |
| $A,x$ | $B=A+x$；$r=x/A$。 |
| $B,x$ | $A=B-x$；$r=x/A$。 |
| $A,r$ | $x=Ar$；$B=A+x=A(1+r)$。 |
| $B,r$ | $A=B/(1+r)$；$x=Ar$。这是本课两种速算方法重点处理的情形。 |
| $x,r$ | $A=x/r$；$B=A+x$。 |

## 二、415 分数法

增长率能换成简单分数时，先想三量的**份数关系**，再计算。若 $r=1/n$，则“基期∶增长量∶现期”为 $n:1:(n+1)$：$B$ 占 $n+1$ 份，$x$ 占 1 份。$r=25\%=1/4$ 时是 $4:1:5$，因此称“415”；例如 $B=780$，则 $x=780/5=156$，$A=624$。

下降时，负号放在增长量上：若 $r=-1/n$，三量为 $n:(-1):(n-1)$。例如 $B=844$、$r=-1/5$，现期是 4 份，$x=-844/4=-211$，$A=844+211=1055$。

本课要求熟悉 $1/9$ 至 $1/2$ 的常见分数，并补充 $2/7\approx28.6\%$、$3/7\approx42.9\%$、$1/11\approx9.1\%$；$-9.1\%$ 可近似看成 $-1/11$。**增长率恰好等于分数时，份数关系精确；仅接近分数时，结果是估算**。能据选项确定答案就停止；选项要求更高精度时再换算法或修正。

## 三、假设分配

已知 $B,r$ 时，把现期 $B$ 分给基期 $A$ 和增长量 $x$，其中 $x=Ar$。先分大头，再分余数；这相当于把 $B/(1+r)$ 的直除过程横着写。直除中每次确定的一段基期，对应一段“基期 $+$ 该段的增长量”；减出的余数留待下一步分配。

1. **先选方便的基期 $A_0$**：取接近实际基期、便于乘 $r$ 的整百、整千或 $500$ 等数。$500$ 可先按 $1000$ 计算再取一半。
2. **分出第一段增长量 $x_0\approx A_0r$**：按需要的精度取整；同时留意 $x_0$ 是估大还是估小。
3. **求未分配的余数 $D=B-(A_0+x_0)$**：正数继续分，负数从前两部分收回。第二步先估其中应给增长量的部分 $\Delta x$，其余 $\Delta A=D-\Delta x$ 给基期；结合第一步的误差作小幅调整。
4. **合并**：$A\approx A_0+\Delta A$，$x\approx x_0+\Delta x$；两项合计仍应为 $B$。需要多求几个基期或增长量、再作和差时，这种分配便于连续计算。

贯穿例：$B=645$、$r=5.6\%$。先给基期 $600$，其增长量 $600\times5.6\%=33.6\approx34$；已分 $634$，余 $11$。第一步的 $34$ 已偏大 $0.4$，第二步可把 $11$ 暂给基期，得到 $A\approx611$、$x\approx34$。精确值约为 $A=610.80$、$x=34.20$；这里的整数分配服务于选项判断。

### 第二步如何分

余数较小、$r$ 在 $0$—$25\%$ 时，可用 $10\%$ 或 $20\%$ 估给增长量的部分，再看第一步误差微调。$r$ 接近常见分数时，可直接估算“余数中增长量占几份”：

| $r$ 所在位置 | 第二步余数中给增长量的比例 |
| --- | --- |
| 约 $16.7\%=1/6$、$20\%=1/5$ | 分别约 $1/7$、$1/6$。 |
| 约 $25\%=1/4$、$33.3\%=1/3$ | 分别约 $1/5$、$1/4$。 |
| 约 $42.9\%=3/7$ | 约 $3/10=0.3$。 |
| 约 $50\%=1/2$ | 约 $1/3$。 |
| 约 $66.7\%=2/3$、$80\%=4/5$ | 分别约 $2/5=0.4$、$4/9$；课堂也将后者粗估为 $0.4$。 |
| 约 $100\%$ | 先近似平分，再按实际增长率调整。 |

依据是：若 $r=m/n$，基期、增长量、现期分别占 $n:m:(n+m)$ 份，所以余数中给增长量的比例为 $m/(n+m)$。**这张表用于余数的第二步估算**；当原增长率并不恰好等于表中分数时，不能把比例当作精确值直接套在全部现期上。

## 四、选项极近时利用选项

先粗估并排除明显不在范围内的选项。若相邻选项的差距已小于截位或假设分配的误差，就从接近的选项中取一个**便于相减的候选增长量** $x_0$，反推出候选基期 $A_0=B-x_0$，再算 $A_0r$ 与选项比较。候选 $x_0$ 的偏差经过乘 $r$ 后会缩小；是否足以判别，仍要看它与选项间距的关系。下降题若以正数表示“减少量” $y$，则候选基期为 $A_0=B+y_0$，再算 $A_0|r|$。

课堂截图例：$B=5505$、$r=9.2\%$，问同比增长量；相近选项有 $463.8$ 和 $465$。取便于相减的 $x_0=465$，则 $A_0=5505-465=5040$，$A_0r=5040\times9.2\%=463.68$，靠近 $463.8$。若仅把现期截成三位，舍去的个位数已大于两个选项的差距，不能靠粗估定选项。

另一课堂截图例：$B=14265$、$r=17.0\%$，问比上年增加多少元；相近选项为 $2072.7$ 和 $2065.7$。先估增量在两千出头，排除远离的选项。为使基期好算，取候选 $x_0=2065$，得 $A_0=14265-2065=12200$；再算 $12200\times17\%=2074$，与 $2072.7$ 更近，选 A。这里 $2065$ 是为反推而选的试算值，$2074$ 也是试算结果；精确增量约为 $2072.69$。

下降例：$B=13140.6$ 亿元、$r=-4.05\%$，问同比减少多少亿元。把减少量记为正数 $y$，则 $B=A-y$、$y=4.05\%A$，因此试算时应由现期**加回减少量**求基期。选项在 $511$—$578$ 亿元之间，取便于凑整的 $y_0=560$，得到 $A_0=13140.6+560=13700.6$；再算 $A_0\times4.05\%\approx548+7=555$，对应 C 项 $555$ 亿元。若正向列式，则 $y=B\times4.05\%/(1-4.05\%)\approx554.66$ 亿元。反推在这里省去了直接除以 $0.9595$ 的计算。
